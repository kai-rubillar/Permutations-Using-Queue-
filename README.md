**Simple 5 Element Queue Permutation**

1. Queue Implementation: Accept five elements from the user, enqueue them into a Queue, display the Queue, and dequeue two elements. Display the updated Queue after the dequeue operations.

2. Permutations: Allow the user to specify the number of elements to arrange. Generate and display all possible permutations of the selected elements.

3. Total Count: Display the total number of permutations generated.
